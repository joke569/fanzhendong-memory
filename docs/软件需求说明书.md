## 1. 项目背景与目标

樊振东的职业生涯横跨二十余年，单纯的时间线容易变成资料堆叠。本项目希望用「生涯 / 球衣 / 球拍」三条线，把比赛、颜色与手感组织成一份可探索的数字回忆录：

- 用户可以在主界面自动流动的卡片中回看 22 段记忆；
- 可以按三条线切换，进入详情阅读长文与引用；
- 可以收藏、写手记，应用关闭后再次打开仍能恢复；
- 探索与收藏的数量会触发轻量成就，形成“越看越想看”的探索闭环。

目标不是做资料百科，而是做一份有情绪、有节奏、可回访的回忆档案。

## 2. 用户与使用场景

**目标用户**：乒乓球爱好者、樊振东球迷、移动应用开发课程评审教师。

**典型场景**：

1. 通勤路上打开应用，自动播放回忆卡片，看到 2024 巴黎。
2. 切换到「球衣」线，比较 2016、2021、2024 三件战袍的颜色变化。
3. 进入详情，读完一段故事，写一句自己的回忆手记。
4. 在时间线里按「球拍」筛选，看从纯木到芳碳的器材变化。
5. 关闭应用，第二天打开，直接回到上次看到的那一段。

## 3. 功能需求

### 3.1 主界面 · 回忆流

- 纵向 `Swiper` 自动轮播 22 条记忆，间隔 6.5 秒，可手动上下滑动。
- 每张卡片展示：海报、线标签、日期、年份、标题、副标题、流动字幕。
- 底部胶片带横向展示全部缩略图，点击可跳转；当前项高亮。
- 底部玻璃 Dock 提供「生涯 / 球衣 / 球拍」三个入口，点击过滤；「全部」按钮恢复全量。
- 顶部显示当前进度（如 `08 / 22`）、时间线入口、设置入口。
- 切换条目时保存 `lastId`，切换线时保存 `lastLine`。

### 3.2 详情页

- 展示大图、线标签、日期、年份、标题、副标题、正文、引用、标签。
- 球衣显示配色与面料；球拍显示配置；所有条目显示时间。
- 收藏按钮：收藏 / 取消收藏，状态即时反馈。
- 回忆手记：多行输入，保存至 Preferences；重新进入详情恢复。
- 上一段 / 下一段：在 22 条记忆中循环切换。
- 返回主界面后，收藏状态同步。

### 3.3 时间线

- 按时间顺序列出全部记忆。
- 支持「全部 / 生涯 / 球衣 / 球拍」筛选。
- 条目显示缩略图、日期、线、标题、副标题、序号。
- 点击条目进入详情。

### 3.4 设置与成就

- 减少动态效果：关闭 Swiper 自动播放与 Marquee 流动字幕，并持久化。
- 清空收藏与手记：清除 Preferences 中的收藏、手记、访问记录。
- 探索进度：显示已访问条目数 / 22。
- 条件成就：
  - `visited >= 10` → 解锁「巴黎的金色雨」；
  - `favorites >= 5` → 解锁「三线收藏家」。
- 关于与素材版权说明。

### 3.5 数据恢复

应用启动时读取 Preferences：

- 有 `lastId` 且在当前 `lastLine` 中：恢复到该条；
- `lastId` 不在当前线：回到该线第 1 条；
- 无数据：默认「全部」第 1 条；
- JSON 损坏：捕获异常并回退空数组，不崩溃。

## 7. 接口设计

| 接口 / 方法 | 输入 | 返回 | 异常 / 边界 |
|---|---|---|---|
| `getMemories(line?: MemoryLine)` | 线枚举，可空 | MemoryItem[] | 空线返回全量；未知线由调用方兜底 |
| `getMemoryById(id: string)` | id | MemoryItem \| undefined | 找不到返回 undefined，页面回退第一条 |
| `MemoryStore.init(context)` | UIAbilityContext | Promise<void> | 单例初始化，重复调用不重复创建 |
| `MemoryStore.load()` | 无 | Promise<MemoryState> | 无数据返回默认状态；JSON 异常回退空数组 |
| `MemoryStore.saveState(state)` | MemoryState | Promise<void> | put + flush；失败不阻塞 UI |
| `MemoryStore.getNote(id)` | id | Promise<string> | 无记录返回空字符串 |
| `MemoryStore.saveNote(id, note)` | id, string | Promise<void> | 空字符串视为清除 |
| `MemoryStore.clearAll()` | 无 | Promise<void> | clear + flush |
| `selectFilter(line)` | string | void | 过滤 items，currentIndex 归零 |
| `selectItem(item)` | MemoryItem | void | 不在当前线时自动回到全量 |
| `openDetail(item)` | MemoryItem | void | router.pushUrl，携带 id |
| `step(delta)` | number | void | 循环切换，越界取模 |

## 9. 异常与边界处理

1. **Preferences 读取失败 / JSON 损坏**：`try/catch` 返回空数组，页面仍可启动。
2. **lastId 不属于当前线**：回退到该线第 1 条，避免 Swiper 空索引。
3. **图片资源缺失**：构建期由资源表校验；运行期由 ArkUI 显示占位/空白，不崩溃。
4. **快速连续切换**：`currentIndex` 使用取模与边界 clamp，避免越界。
5. **手记超长**：`TextArea` 限制 240 字；保存前 `trim`。
6. **清空数据**：二次确认；清空后回到默认状态。
7. **减少动态效果**：关闭自动播放与字幕，保留手动滑动。

| 异常 | 清空 Preferences 后启动 | 默认 all / 第 1 条 |
